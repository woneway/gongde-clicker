# 赛博木鱼 Cyber Muyu 🐟

> 免费在线电子木鱼 / 功德点击器 —— 点一下,功德 +1。适合上班摸鱼、学习间隙和日常解压。

**🔗 在线体验:[gongdeclicker.com](https://gongdeclicker.com)**

打开网页,点击木鱼或按下空格键,给今天加一点功德。无需下载、无需注册,打开即用。

## ✨ 功能

- 🐟 **一键敲木鱼** —— 点击或按空格,功德 +1,带音效与动画反馈
- 🔥 **连击系统** —— 连续敲击进入心流状态
- 🎴 **功德签** —— 随机抽取功德签文
- 🏆 **成就系统** —— 解锁不同里程碑
- 📱 **移动端适配** —— 手机、平板、桌面均可流畅使用
- 📖 **木鱼文化 Blog** —— 木鱼历史、功德与福德之辨、解压原理等原创内容

## 🛠️ 技术栈

- [Next.js](https://nextjs.org/)(App Router,静态导出)
- React
- 部署于 Cloudflare Pages / Vercel

## 🚀 本地开发

```bash
npm install
npm run dev        # 本地开发
npm run build      # 生产构建
```
